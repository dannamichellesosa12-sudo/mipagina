¿QUÉ SON LAS ETIQUETAS SEMÁNTICAS?

REGRESAR

Las etiquetas semánticas en HTML son elementos de código que comunican el significado y la función de su contenido tanto al navegador como a los motores de búsqueda, en lugar de actuar como simples contenedores visuales. Al usar etiquetas como <header>, <article> o <footer> en vez de un <div> genérico, se define claramente qué parte es la cabecera, cuál es el texto principal o cuál es el pie de página. Esto mejora drásticamente el posicionamiento SEO, facilita la accesibilidad para personas que usan lectores de pantalla y hace que el código sea mucho más limpio y fácil de mantener.

<header>

La etiqueta <header> representa la cabecera de una página o de una sección. Puede contener el logotipo, el título, una descripción o el menú de navegación.

Ejemplo de uso:

<header>
    <h1>Mi página web</h1>
    <p>Bienvenido a mi sitio web</p>
</header>

<section>

La etiqueta <section> representa una sección temática dentro de una página. Se utiliza para organizar el contenido en diferentes apartados.

Ejemplo de uso:

<section>
    <h2>Mis proyectos</h2>
    <p>Estos son algunos de mis proyectos.</p>
</section>

<article>

La etiqueta <article> representa un contenido independiente que puede ser distribuido o reutilizado por sí mismo, como una noticia, publicación o artículo.

Ejemplo de uso:

<article>
    <h2>Nuevo artículo</h2>
    <p>Este es el contenido de mi artículo.</p>
</article>

<aside>

La etiqueta <aside> contiene información relacionada de manera indirecta con el contenido principal, como barras laterales, enlaces adicionales o anuncios.

Ejemplo de uso:

<aside>
    <h3>Información adicional</h3>
    <p>Aquí puedes encontrar información relacionada.</p>
</aside>

<footer>

La etiqueta <footer> representa el pie de página de un documento o de una sección. Normalmente contiene información de contacto, derechos de autor o enlaces.

Ejemplo de uso:

<footer>
    <p>© 2026 Mi página web</p>
    <p>Todos los derechos reservados.</p>
</footer>

<nav>

La etiqueta <nav> representa una sección que contiene enlaces de navegación hacia otras páginas o partes importantes del sitio web.

Ejemplo de uso:

<nav>
    <a href="index.html">Inicio</a>
    <a href="contacto.html">Contacto</a>
    <a href="nosotros.html">Nosotros</a>
</nav>

<main>

La etiqueta <main> representa el contenido principal de una página. Debe contener la información central y única del documento.

Ejemplo de uso:

<main>
    <h1>Contenido principal</h1>
    <p>Esta es la información principal de la página.</p>
</main>

<address>

La etiqueta <address> se utiliza para proporcionar información de contacto del autor, propietario o responsable de una página o artículo.

Ejemplo de uso:

<address>
    Contacto: ejemplo@correo.com<br>
    Teléfono: 555-123-4567<br>
    Ciudad de México, México
</address>
