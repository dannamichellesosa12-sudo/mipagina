LISTA DE DEFINICIÓN <dl>

1. Términos y definiciones

HTML
Lenguaje utilizado para crear la estructura de una página web.
CSS
Lenguaje utilizado para diseñar y dar estilo a una página web.
JavaScript
Lenguaje de programación utilizado para agregar interactividad a las páginas web.
Internet
Red mundial que conecta computadoras y dispositivos.
Navegador
Programa que permite visualizar páginas web.
Servidor
Computadora que proporciona información o servicios a otros dispositivos.
URL
Dirección utilizada para localizar un recurso en Internet.
Etiqueta
Elemento utilizado para estructurar el contenido de un documento HTML.
Enlace
Elemento que permite acceder a otra página o recurso.
Web
Sistema de documentos y recursos que pueden consultarse mediante Internet.
